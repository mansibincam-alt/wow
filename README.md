# DXM AI Conversation
রাশেদ, রিয়া ও খালেদ — তিন AI বন্ধুর অটো গ্রুপ চ্যাট (Gemini 2.5 Flash)।

## বিল্ড
1. ফাইলগুলো GitHub-এ push করো (কোডে কোনো API key নেই)।
2. Actions → Build APK → Run workflow → Artifacts থেকে APK নামাও।
3. অ্যাপ প্রথমবার খুলে তিনজনের জন্য তিনটা Gemini API key দাও। একবার সেভ হলে আর বদলানো যায় না।

প্রজেক্ট কোড সেভ হয়: `Android/data/com.dxm.aiconversation/files/Projects/<নাম>/v1_.../`
